# Vault — Secrets Management and Encryption

HashiCorp Vault securely stores, controls access to, and rotates secrets: API keys, database credentials, TLS certificates, and encryption keys.

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Secrets Engine** | Backend that stores, generates, or encrypts secrets (KV, database, transit, PKI, AWS) |
| **Authentication Method** | How a client proves identity (token, Kubernetes, LDAP, OIDC, AppRole, AWS IAM) |
| **Policy** | ACL-based rules granting or denying access to paths |
| **Dynamic Secrets** | Short-lived, on-demand credentials generated by Vault (e.g., Postgres user) |
| **Transit Engine** | Encryption-as-a-service — encrypt/decrypt data without storing it |
| **KV Store** | Key-value storage for static secrets (v1: versioned, v2: versioned + metadata) |

## Core CLI Commands

```bash
# Start Vault in dev mode (never for production)
vault server -dev

# Export addr and unseal key
export VAULT_ADDR='http://127.0.0.1:8200'
export VAULT_TOKEN='hvs.xxx'

# Enable KV v2 secrets engine
vault secrets enable -path=ml-secrets kv-v2

# Write and read secrets
vault kv put ml-secrets/model-api KEY=sk-abc123 ENDPOINT=https://api.openai.com
vault kv get ml-secrets/model-api

# List secrets
vault kv list ml-secrets

# Enable database dynamic secrets engine
vault secrets enable database

# Configure database (Postgres)
vault write database/config/ml-postgres \
    plugin_name=postgresql-database-plugin \
    allowed_roles="ml-app" \
    connection_url="postgresql://{{username}}:{{password}}@postgres:5432/mlflow" \
    username="vault_admin" \
    password="p@ssw0rd"

# Create a dynamic role (15min TTL)
vault write database/roles/ml-app \
    db_name=ml-postgres \
    creation_statements="CREATE USER \"{{name}}\" WITH PASSWORD '{{password}}' VALID UNTIL '{{expiration}}'; GRANT SELECT, INSERT ON ALL TABLES IN SCHEMA public TO \"{{name}}\";" \
    default_ttl="15m" \
    max_ttl="1h"

# Generate dynamic credentials
vault read database/creds/ml-app
```

## Integration: API Key Management for Model Endpoints

Store and rotate API keys for external model providers (OpenAI, Anthropic, Cohere) and internal service tokens.

### Vault Agent Injector on Kubernetes

```yaml
# deployment.yaml — inject secrets via Vault Agent sidecar
apiVersion: apps/v1
kind: Deployment
metadata:
  name: model-api-gateway
  annotations:
    vault.hashicorp.com/agent-inject: "true"
    vault.hashicorp.com/role: "model-service"
    vault.hashicorp.com/agent-inject-secret-openai-key: "ml-secrets/data/openai"
    vault.hashicorp.com/agent-inject-template-openai-key: |
      {{- with secret "ml-secrets/data/openai" -}}
      export OPENAI_API_KEY={{ .Data.data.key }}
      {{- end }}
spec:
  template:
    spec:
      serviceAccountName: model-service
      containers:
        - name: gateway
          image: ml-gateway:latest
          env:
            - name: VAULT_ADDR
              value: "http://vault:8200"
```

### AppRole Authentication

```bash
# Create policy
vault policy write model-gateway -<<EOF
path "ml-secrets/data/openai" {
  capabilities = ["read"]
}
path "ml-secrets/data/cohere" {
  capabilities = ["read"]
}
path "database/creds/ml-app" {
  capabilities = ["read"]
}
EOF

# Create AppRole
vault write auth/approle/role/model-gateway \
    token_policies="model-gateway" \
    token_ttl="1h" \
    token_max_ttl="24h"

# Get RoleID and SecretID
vault read auth/approle/role/model-gateway/role-id
vault write -f auth/approle/role/model-gateway/custom-secret-id
```

### Python SDK Integration

```python
import hvac
import os
from pathlib import Path

# Read token from Vault Agent injected file
token_path = Path("/vault/secrets/openai-key")
if token_path.exists():
    # Vault Agent injected — parse exported env vars
    with open(token_path) as f:
        for line in f:
            if line.startswith("export "):
                key, val = line.replace("export ", "").strip().split("=", 1)
                os.environ[key] = val.strip('"').strip("'")

# Or authenticate via AppRole
client = hvac.Client(
    url=os.environ["VAULT_ADDR"],
    token=os.environ.get("VAULT_TOKEN"),
)

if not client.is_authenticated():
    client.auth.approle(
        role_id=os.environ["APPROLE_ROLE_ID"],
        secret_id=os.environ["APPROLE_SECRET_ID"],
    )

# Fetch API key for model endpoint
secret = client.secrets.kv.v2.read_secret_version(
    path="openai",
    mount_point="ml-secrets",
)
api_key = secret["data"]["data"]["key"]
```

## Database Credential Rotation

```python
# db_creds.py — dynamic Postgres credentials for MLflow
import hvac
import psycopg2

client = hvac.Client(url="http://vault:8200")
client.auth.kubernetes("model-service")  # K8s auth

# Get short-lived database credentials
creds = client.secrets.database.generate_credentials("ml-app", mount_point="database")
username = creds["data"]["username"]
password = creds["data"]["password"]

# Connect using dynamic creds (valid for 15 minutes)
conn = psycopg2.connect(
    host="postgres",
    dbname="mlflow",
    user=username,
    password=password,
)
```

## Encryption as a Service (Transit)

```yaml
# Enable transit engine
vault secrets enable transit
vault write -f transit/keys/model-weights type=aes256-gcm96
```

```python
# Encrypt model weights before storing in object store
import hvac

client = hvac.Client(url="http://vault:8200")
client.auth.approle(role_id="xxx", secret_id="yyy")

# Encrypt
encrypted = client.secrets.transit.encrypt_data(
    mount_point="transit",
    name="model-weights",
    plaintext=b"model_weights_bytes...".hex(),
)

# Decrypt
decrypted = client.secrets.transit.decrypt_data(
    mount_point="transit",
    name="model-weights",
    ciphertext=encrypted["data"]["ciphertext"],
)
```

## Best Practices

- Never use root tokens in production; always authenticate via Kubernetes or AppRole
- Use dynamic secrets for databases — they auto-expire and rotate
- Enable audit logging (`vault audit enable file file_path=/vault/logs/audit.log`)
- Seal Vault before backing up; use auto-unseal with cloud KMS (AWS KMS, Azure Key Vault)
- Set short TTLs on tokens and secrets — 15-60 minutes for dynamic creds
- Use transit engine for encrypt-at-rest rather than storing keys alongside data
